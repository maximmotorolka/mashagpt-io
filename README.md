# MashaGPT / io.ru — ChatGPT онлайн без регистрации

Клон интерфейса чата [mashagpt.ru/chat](https://mashagpt.ru/chat) без регистрации и подписок.
Чат работает через бесплатный keyless-апи Pollinations (OpenAI-совместимый, стриминг), фолбэк-цепочка моделей + GET-резерв.

- Домен в брэндинге: **io.ru** (оригинальный домен io.ru мёртв с 2001 года)
- Регистрация/логин/оплата: удалены; лимит — «Безлимит»
- Чаты сохраняются в localStorage браузера
- Модели в селекторе: ChatGPT 6.1, Claude Opus 5.5, Gemini 3.0, Grok 4

Сайт размещён на GitHub Pages (хаб). Сборка: без зависимостей, один index.html.
